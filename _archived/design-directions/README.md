# 首页视觉方向探索 · Historical Design Directions

这里保存首页改版期间的三组视觉方向样稿，供历史查阅。它们不是当前网站的额外入口。

- **B · 研究终端**（`terminal.html`）：历史探索，未采用。
- **C · 实验公报**（`bulletin.html`）：历史探索，未采用。

`index.html` 用于在三组样稿之间切换，`overview.jpg` 是方向概览图。样稿中的活动和社团介绍链接指向当前正式页面；保留这些文件是为了记录设计过程。
